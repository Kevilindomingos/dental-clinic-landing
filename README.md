### ✨ Features
- **🌓 Dual Theme** - Light/dark mode toggle
- **📱 Responsive** - Works on all devices
- **💬 WhatsApp** - Direct chat integration
- **⚡ Fast** - Built with Vite + React
- **🎨 Modern UI** - Clean, professional design

### 🛠️ Technologies
- React 18 + TypeScript
- TailwindCSS 3
- Lucide Icons
- Vite

### 📦 Installation

```bash
# Clone repository
git clone https://github.com/yourusername/dental-clinic-landing.git
cd dental-clinic-landing

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
